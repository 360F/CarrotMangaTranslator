## 사용자 확인이 필요한 analysis 수준의 기각 (아직 REJECTED 아님)

[RENDERER_CANDIDATE_ANALYSIS §7 Rejected Candidates](../../analysis/RENDERER_CANDIDATE_ANALYSIS.md#7-rejected-candidates)는 renderer 후보 중 SVG+resvg, Satori+resvg, CanvasKit/WASM(first spike), Sharp/libvips(renderer로서), shaping 없는 raw SVG를 기술적 이유와 함께 REJECT로 분류했다.

이것은 분석 에이전트의 권고이며, 이 기각을 사용자가 명시적으로 결정한 기록은 repository에서 찾지 못했다. 사용자가 확인하면 각 후보를 이 파일에 REJECTED item(`M1-RENDER-<NNN>`)으로 옮기고 결정 날짜를 남긴다.
